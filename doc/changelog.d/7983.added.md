Fiber weave generation: add a "Weave Designer" HFSS extension to generate woven glass-fiber fill
geometry for PCB substrates. It supports building a full stackup (ground/substrate/trace/ports/
airbox) or weaving onto an existing layout, with a "Mode" selector to choose between "Design full
stackup" (build ground/substrate/trace/ports/airbox automatically, then weave) and "Weave existing
layout" (assume a complete design, including vias, already exists; only add the weave to
user-named, pre-existing substrate object(s), picked either by typing their names or via a "Get
Selection" button that reads the current 3D modeler selection). The "Geometry..." dialog opens for
every weave style (predefined or "Custom") and grays out the glass dimension fields for predefined
vendor styles (only "Custom" allows editing them). Shift X, Shift Y and Rotation are available in
the main window. Low-level attributes (yarn material, facet/sector discretization) are exposed in
a separate "Advanced Settings" dialog.
