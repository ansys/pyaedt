Weave Designer extension: the "Geometry..." dialog now opens for every weave style (predefined
or "Custom") and grays out the glass dimension fields for predefined vendor styles (only
"Custom" allows editing them). Shift X, Shift Y and Rotation moved to the main window (under
"Resin Df"). Remaining low-level attributes (yarn material, facet/sector discretization) moved
to a new "Advanced Settings" dialog.
